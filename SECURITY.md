# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

As an autonomous publishing pipeline, security (including credential protection, API key rotation, SSRF prevention, and rate-limiting) is critical.

If you find a security issue or vulnerability:
1. Please do not open a public issue.
2. Email **Musfiqur Rahman Saimon** at `saimon@ascentraconsulting.co.uk` with the details and reproduction steps.
3. Vulnerabilities will be triaged and addressed within 48 hours.
