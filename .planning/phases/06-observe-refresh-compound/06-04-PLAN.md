## Phase Boundary Context
Phase 6 completes the autonomous compounding vision of TierOne AutoBlog.
Plan 06-04 implements the publishing velocity scaling governor and automated pillar hub promotion engine (GROW-03):
1. **4-Point Velocity Governor (`lib/pipeline/publish/governor.ts`)**: Prevents daily publication until the domain has operated for $\ge 60$ days with $\ge 70\%$ indexation, 0 circuit-breaker trips in 30 days, and $\ge 10$ live indexed articles.
2. **Autonomous Cadence Graduation**: Integrated into `scripts/publish-scheduled.ts`, non-scheduled daily runs (Tue, Thu, Sat) exit cleanly with code 0 while locked, then automatically start publishing when criteria are met.
3. **Pillar Hub Dynamic Promotion (`app/[silo]/page.tsx`)**: Upgrades silo landing pages into rich Pillar Hubs when article counts reach $\ge 8$ (up to 12), introducing thematic sub-clusters and `CollectionPage` JSON-LD structured data.
4. **Cornerstone Guide & Bidirectional Link Mesh**: Queues flagship guides (`/blog/{silo}-complete-guide`) and verifies interlinking between pillar and spokes.

## Decisions Handled
- **D-07:** Strict 4-Point Baseline Gate (domain age $\ge 60$d, index ratio $\ge 70\%$, 0 trips in 30d, $\ge 10$ live articles).
- **D-08:** Runtime Velocity Governor (`lib/pipeline/publish/governor.ts` hooked into `scripts/publish-scheduled.ts`).
- **D-09:** Silo Cluster Threshold & Dual Promotion ($\ge 8$ articles elevates landing to Pillar Hub and queues cornerstone guide).
- **D-10:** Automated Bidirectional Link Mesh (Pillar Hub links to all spokes; spokes carry breadcrumbs and related links to Pillar).
</plan_context>

1. Create `lib/pipeline/publish/governor.ts`:
   - Export interfaces:
     ```typescript
     export interface GovernorEvaluation {
       unlocked: boolean;
       domainAgeDays: number;
       domainAgePassed: boolean;
       indexationRatio: number;
       indexationPassed: boolean;
       circuitBreakerTrips30d: number;
       stabilityPassed: boolean;
       activeCorpusCount: number;
       corpusPassed: boolean;
       reasons: string[];
     }

     export interface GovernorCheckOptions {
       keywordsDir?: string;
       siteUrl?: string;
       now?: Date;
       mockIndexRatio?: number;
     }
     ```
   - Export function `checkVelocityGovernor(options?: GovernorCheckOptions): GovernorEvaluation`:
     * Criterion 1 (Domain Operating Age $\ge 60$d):
       - Scans `content/keywords/*/registry.json` for all entries with `stage === 'published'`.
       - Finds the earliest `publishedAt` timestamp.
       - If no published posts or `ageDays < 60`: `domainAgePassed = false`, records reason.
     * Criterion 2 (Indexation Ratio $\ge 70\%$):
       - If `options.mockIndexRatio !== undefined`, uses it.
       - Otherwise, loads indexation ratio from `content/analytics/snapshot.json` or live GSC.
       - Requires `ratio >= 0.70`.
     * Criterion 3 (Operational Stability - Circuit Breaker Clean):
       - Reads `content/keywords/pipeline-state.json`.
       - Checks `paused === false`.
       - Inspects `failures` log: requires 0 failures/trips in the last 30 days (`now - timestamp < 30 * 86400000`).
     * Criterion 4 (Active Corpus Floor $\ge 10$):
       - Counts total published entries across all silo registries.
       - Requires `activeCorpusCount >= 10`.
     * Aggregation:
       - Sets `unlocked = domainAgePassed && indexationPassed && stabilityPassed && corpusPassed`.
       - Returns complete `GovernorEvaluation`.
2. Update `scripts/publish-scheduled.ts`:
   - Import `checkVelocityGovernor`.
   - Determine whether today is a baseline scheduled day or an expanded daily run:
     * Baseline Days (4x/week): Sunday (0), Monday (1), Wednesday (3), Friday (5).
     * Expanded Days: Tuesday (2), Thursday (4), Saturday (6).
   - If today is an expanded day:
     * Call `const governor = checkVelocityGovernor()`.
     * If `!governor.unlocked`:
       - Log notice: `[governor] Velocity gate locked (<60d baseline): skipping non-scheduled daily publish.`
       - Log details: `[governor] Locked reasons: ${governor.reasons.join('; ')}`.
       - Exit cleanly with code 0 (`process.exit(0)`). (Prevents false alarms and DLQ failures).
     * If `governor.unlocked`:
       - Log notice: `[governor] 60-day baseline criteria fully met. Daily publication unlocked.`
       - Proceed with candidate selection and publication.
3. Create `tests/velocity-governor.test.ts`:

   - Test All Passing: age >= 60d, ratio >= 0.70, clean state, >= 10 posts -> `unlocked: true`.
   - Test Day Gating: mock Tuesday with locked governor exits 0; mock Monday runs normally.

<threat_model>
### Threat Ref T-06-07: Premature Velocity Scaling & Google Spam / Sandboxing Penalty
- **Threat:** Accelerating publishing velocity from 4x/week to daily on a brand new domain before Google has established crawl trust and indexing baselines triggers algorithmic spam heuristics or sandbox demotion.
- **Mitigation:** The velocity governor enforces a hard 4-point gate: domain operating age $\ge 60$ days, live sitemap indexation ratio $\ge 70\%$, zero circuit breaker trips in the past 30 days, and $\ge 10$ actively indexed articles. On non-scheduled days, the publisher exits with code 0 without publishing until all 4 criteria are verified.
- **Verification:** Unit test in `tests/velocity-governor.test.ts` tests all boundary conditions (e.g. 59 days old, 69% index ratio, 1 trip), confirming that velocity remains strictly locked at 4x/week until every requirement is met.

### Threat Ref T-06-08: Broken Silo Architecture & Orphaned Spoke Degradation
- **Threat:** As a silo grows past 8 articles, spoke posts fail to interlink with the central silo landing, diluting PageRank and leaving deep articles orphaned from Googlebot crawl paths.
- **Mitigation:** Silo landing pages automatically upgrade into rich Pillar Hubs with `CollectionPage` structured data linking all spokes in the cluster. The cluster analysis tool (`lib/pipeline/hubs/pillar.ts`) validates bidirectional linking between the pillar and every spoke, queuing a dedicated cornerstone guide to serve as the cluster's authority anchor.
- **Verification:** Test assertions in `tests/pillar-hub.test.ts` verify that the generated `CollectionPage` JSON-LD contains every post in the silo and that missing bidirectional links are reported.
</threat_model>
