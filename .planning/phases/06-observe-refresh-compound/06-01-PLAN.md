## Phase Boundary Context
Phase 6 delivers the compounding growth and observation layer for TierOne AutoBlog.
Plan 06-01 builds the data ingestion foundation and owner-facing analytics dashboard (GROW-01):
1. **Multi-Source Data Ingestion**: GSC Search Analytics API (`country × page × query`) and Plausible Stats API (`visit:country` breakdown).
2. **Tier-1 Normalization & Headline Metrics**: Normalized aggregation of US, UK, CA, and AU traffic share, along with live sitemap indexation ratios against the $\ge 70\%$ benchmark.
3. **Offline Resilience & Zero-Cost Policy**: Full fallback to `content/analytics/snapshot.json` or deterministic synthetic data when API credentials are absent, adhering strictly to the fully-free platform directive.
4. **Confidential Dashboard Route (`/dashboard`)**: Next.js 16 App Router Server Component secured via secret token query parameter (`?token=...`), returning HTTP 404 (`notFound()`) for unauthorized access and disallowing robot indexing.

## Decisions Handled
- **D-01:** Protected Dashboard Route (`app/dashboard/page.tsx`, `process.env.DASHBOARD_SECRET`, `notFound()` on unauthorized).
- **D-02:** Country-Segmented Data Sourcing & Offline Resilience (GSC API + Plausible API + `content/analytics/snapshot.json` fallback).
- **D-03:** Headline Metrics & Visual Indicators (Tier-1 search/traffic share headline + indexed-vs-submitted $\ge 70\%$ gauge + country-filtered query breakdown).
</plan_context>

   - Export helper `normalizeGscCountry(code: string): string`.
   - Export function `fetchGscSearchAnalytics(options: { siteUrl: string; startDate: string; endDate: string; clientEmail?: string; privateKey?: string }): Promise<{ rows: GscSearchRow[]; sitemapRatio: SitemapRatioData } | null>`:
     * Obtains auth via `getGscAuth` from `lib/pipeline/indexing/google-search-console.ts`.
     * If auth is null (credentials unset), returns null immediately without throwing.
     * Calls `searchconsole.searchanalytics.query` with dimensions `['country', 'page', 'query']`, rowLimit 5000.
     * Calls `searchconsole.sitemaps.list` to calculate submitted vs indexed counts across web sitemaps.
     * Normalizes rows into `GscSearchRow[]`.
     * Handles API errors gracefully by logging a warning and returning null.
3. Create `lib/pipeline/analytics/plausible.ts`:
   - Export function `fetchPlausibleStats(options: { siteId: string; apiKey?: string; period?: string }): Promise<PlausibleCountryRow[] | null>`:
     * Checks `apiKey ?? process.env.PLAUSIBLE_API_KEY`. If unset, returns null immediately without throwing.
     * Fetches `https://plausible.io/api/v1/stats/breakdown?site_id=${siteId}&period=${period || '30d'}&property=visit:country&metrics=visitors,visits,bounce_rate,visit_duration`.
     * Handles non-200 responses or fetch failures by returning null.
4. Create `lib/pipeline/analytics/snapshot.ts`:
   - Export function `loadAnalyticsSnapshot(filePath?: string): GrowthAnalyticsData | null`:
     * Reads `content/analytics/snapshot.json`. Returns null if file does not exist or JSON parsing fails.
   - Export function `saveAnalyticsSnapshot(data: GrowthAnalyticsData, filePath?: string): void`:
     * Writes formatted JSON to `content/analytics/snapshot.json` ensuring directory exists.
   - Export function `generateSyntheticAnalytics(postsDir?: string): GrowthAnalyticsData`:

     * Generates simulated Tier-1 share (~82-88%), GSC queries, and sitemap indexation ratio (e.g. 9/11 indexed = 81.8%).

     * If live data fails or credentials are unset: loads `loadAnalyticsSnapshot()`. If present, returns with `source: 'snapshot'`.
     * If snapshot absent: returns `generateSyntheticAnalytics()`, tagged `source: 'synthetic'`.
6. Create initial `content/analytics/snapshot.json` populated with valid sample metrics so offline testing has an immediate baseline.

<threat_model>
### Threat Ref T-06-01: Sensitive Search Analytics Exposure & Missing Credential Pipeline Crash
- **Threat:** Private search queries, CTRs, and commercial keyword intent data leak to public scrapers or search engine competitors; or pipeline crashes in CI/local runs when external API credentials are unconfigured.
- **Mitigation:** The dashboard route exports `robots: { index: false, follow: false }` and fails closed behind `notFound()` when the secret token is absent. API clients verify credentials before instantiation and cleanly fall back to `content/analytics/snapshot.json` or deterministic synthetic data without throwing unhandled exceptions.
- **Verification:** Unit tests in `tests/dashboard-route.test.ts` verify that requests without a token trigger 404, and that analytics fetcher functions return valid structured data when credentials are completely unset.

### Threat Ref T-06-02: Unauthorized Dashboard Access & Token Leakage
- **Threat:** Unauthorized third parties discover the dashboard route through path enumeration and access proprietary performance data without credentials.
- **Mitigation:** Route uses `notFound()` from `next/navigation` rather than a 401/403 status code. To unauthorized visitors or automated scanners, `/dashboard` returns the exact same 404 page as a non-existent URL, leaking no information about the route's existence.
- **Verification:** Test assertions in `tests/dashboard-route.test.ts` confirm that invalid, empty, or malicious tokens invoke `notFound()`.
</threat_model>
