## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, anchor-link offset |
| sm | 8px | Compact element spacing, list-item gaps, badge padding |
| md | 16px | Default element spacing, card padding, callout padding (`p-4`) |
| lg | 24px | Section padding, article vertical rhythm (`space-y-6`) |
| xl | 32px | Layout gaps, homepage card gaps (`gap-8`) |
| 2xl | 48px | Major section breaks, trust-page block gaps |
| 3xl | 64px | Page-level spacing, hero/footer vertical padding (`py-16`) |

Exceptions: ad-slot fixed ad-industry dimensions only — `728×90` (header leaderboard, desktop)
and `336×280` (in-article reservation). These are IAB standard sizes, not spacing tokens;
rendered as invisible fixed-dimension divs with `width`/`height` inline styles (D-11). Touch targets
meet 44px minimum on mobile TOC `<details><summary>` and nav links via `py-3` (12px × 2 + text).

## 1. Brand System

- **Name/tagline/domain (single source):** `lib/site.ts` exports exactly `SITE_NAME='AI Tool Digest'`,
  `SITE_TAGLINE='Practical AI tool guides for busy builders'`, `SITE_URL='https://exclusivesources.online'`,
  `AUTHOR_NAME='Musfiqur Rahman Saimon'`, `AUTHOR_SLUG='musfiqur-rahman-saimon'`,
  `CONTACT_EMAIL='saimon@ascentraconsulting.co.uk'`, `LINKEDIN_URL`, `GITHUB_URL`.
  Every component/route imports from `@/lib/site` — never hardcodes these strings.
  (D-01 alternatives for owner approval live in plan SUMMARYs only, never in code.)
- **Logo (`components/logo.tsx`):** minimal inline SVG mark + wordmark. Geometry: one simple
  geometric mark (square/diamond/spark in `#4f46e5`, ~28×28 viewBox) + `SITE_NAME` wordmark
  in semibold system sans 18px `#171717`. Zero image requests — no `<Image>`, no SVG file,
  no favicon-image dependency beyond `public/favicon.svg` (geometric echo of the mark).
  Header height fixed `h-16`; logo lockup left-aligned, vertically centered.
- **Editorial light theme (D-03):** `bg-white text-[#171717]` base. Secondary surfaces
  `bg-slate-50` (footer band, code-block header strip, table header row). Borders `border-slate-200`.
  Muted text `text-slate-600` (dates, excerpts, footer). One accent `#4f46e5` per reserved list.
  No dark mode, no toggle, no `dark:` variants anywhere, no theme script.
- **Type scale (web):** 14 label / 16 body / 20 H3 / 24 H2 / 30 post-H1 / 36 homepage-H1.
  Weights 400 + 600 only. Body 1.5, headings 1.2. Article prose renders through
  `@tailwindcss/typography` `prose prose-slate max-w-none` inside the measure container.
- **No-webfont rule (D-10):** zero `next/font` imports, zero `<link>` to font CDNs, zero
  `@font-face`. OG images use system/built-in fonts only (no remote `fetch` at render).
- **Favicon:** `public/favicon.svg` — flat `#4f46e5` geometric mark on white, no text.

## 3. Homepage Spec (`app/page.tsx` — latest-posts index, D-09)

- **Structure:** H1 = `SITE_NAME` 36px semibold + tagline paragraph 16px muted directly under.
  Post list below: `<ul className="mt-8 grid gap-8">`, one `<li>` per post, newest first
  (sorted by `publishedAt` desc from typed `allPosts` import).
- **Card anatomy (no silo assumptions, no images, no client JS):**
  1. Title link: H2 20–24px semibold `hover:text-[#4f46e5]`, href `/blog/{slug}`.
  2. Excerpt: `description` frontmatter, 16px `text-slate-600`, 2-line clamp.
  3. Meta row 14px muted: `{formatted date} · {readingMinutes} min read`
     (readingMinutes = `readingTime(wordCount)`, `Math.max(1, Math.ceil(words / 200))`).

  `Fresh AI tool guides are on the way. Check back soon.` No skeleton, no spinner.
- **No pagination, no search, no filters, no sidebar, no newsletter form in Phase 1.**
  Phase-2 archives/tags/pagination are noindexed when they arrive — homepage stays indexable.

## 4. Article Template Spec (`app/blog/[slug]/page.tsx`, SITE-02 core)

- **Route contract:** flat `/blog/{slug}`, `generateStaticParams` over all posts,
  `generateMetadata` per post (title 50–60 chars, description 150–160, canonical
  `${SITE_URL}/blog/${slug}` built only from `SITE_URL` + schema-validated slug,
  OG/Twitter images pointing at the per-post `opengraph-image` route).
- **Measure + grid:** article column `max-w-[65ch]` (~65ch narrow measure, D-05).
  Desktop `lg:` two-column: `grid lg:grid-cols-[minmax(0,65ch)_220px] gap-8`;
  TOC column sticky. Mobile: single column, TOC collapses inline (below).
- **Reading order (top → bottom):**
  1. `<ReadingProgress/>` (sole client island, fixed top — see below).
  2. H1 30px semibold (frontmatter `title`), tight `leading-[1.2]`.
  3. `<Byline/>` 14px muted row (see §9).
  4. `<AiBadge/>` visible per-post disclosure (see §9).
  5. Hero: none in Phase 1 (no hero images until Phase 3 image pipeline).
  6. `<Tldr/>` box — MANDATORY within first 100 words (D-06), rendered from `tldr` frontmatter.
  7. `<TocInline>` (`<details>`, mobile only, `lg:hidden`) with `<summary>On this page</summary>`.
  8. MDX body (`prose prose-slate max-w-none`): ≥3 H2s with H3 subsections, short 2–3 sentence
     paragraphs, bold takeaway line per H2, ≥1 GFM comparison table, ≥1 list,
     ≥1 fenced code block where natural, one `<Callout>`, conclusion H2 + CTA paragraph
     linking `/about` (exact href), `Sources` H2 listing 2–3 real sources by name+URL.
  9. In-article ad reservation `<AdSlot id="in-article" width={336} height={280}/>`
     placed after the 2nd H2 (invisible, `aria-hidden`, zero shift).
  10. FAQ static list: H2 `Frequently asked questions` + `<section aria-label="Frequently asked questions">`
      of 3–5 `{q → H3, a → paragraph}` pairs from frontmatter `faq` (SAME strings feed
      FAQPage JSON-LD — single-source rule, ARCHITECTURE Pattern 4). NO accordion,
      NO `<details>` on FAQs in Phase 1 (D-08).
  11. `<RelatedPosts/>` (see §9).
- **TOC (desktop/mobile, D-05):** `<Toc headings={...}>` — headings extracted at build from
  rehype-slug ids, passed as prop (no client-side DOM scraping). Desktop:
  `<nav aria-label="Table of contents" className="toc-sidebar hidden lg:block sticky top-24">`,
  anchor links 14px, accent left-border on active section (active state via CSS `:target`
  only — no scroll-spy JS). Mobile: `<TocInline>` = `<details className="lg:hidden"><summary
  className="py-3">On this page</summary><ul>…` — 44px touch target via `py-3`.
- **TL;DR (`<Tldr title="TL;DR" items={string[]}>`):**
  `<aside aria-label="TL;DR summary" className="tldr-box rounded-lg border border-indigo-200 bg-indigo-50 p-4 my-6">`,
  title 14px semibold + checkmark `<ul>` (inline SVG check, no icon lib), items 16px/1.5.
  Content = `tldr` frontmatter (≤100 words).
- **Callouts (`<Callout variant="info"|"warning"|"success" title={string}>`):**
  base `rounded-lg border border-l-4 p-4 my-6` + `role="note"`;
  info `border-sky-200 bg-sky-50` (title `text-sky-900`), warning `border-amber-200 bg-amber-50`
  (title `text-amber-900`), success `border-emerald-200 bg-emerald-50` (title `text-emerald-900`).
  Title 14px semibold, body 16px/1.5. MDX usage: `<Callout variant="info" title="…">…`.
- **Tables:** GFM via `remark-gfm`. Wrapper `overflow-x-auto my-6` (no page-level horizontal scroll).
  `table w-full text-left text-[14px]`; `thead th bg-slate-50 font-semibold px-4 py-2 border-b border-slate-200`
  (sticky header `sticky top-16` only when table exceeds ~10 rows); striped body
  `tbody tr:nth-child(even):bg-slate-50` (or `even:bg-slate-50`); cells `px-4 py-2 border-b border-slate-100`.
  Required columns shape for comparisons: tool × price/best-for/verdict.
- **Code blocks:** Shiki server-rendered via `rehype-pretty-code` (zero runtime highlighter).
  `pre` gets `rounded-lg p-4 overflow-x-auto text-[14px] bg-slate-950 text-slate-50` (dark code well
  is the single dark-surface exception; prose text stays light). Copy button: minimal inline
  button in code-block header strip (`Copy` → `Copied`, clipboard API, no dependency).
  Copy-button JS is part of the static-plus-touches budget — progress bar remains the only
  `"use client"` route-level island; copy uses a tiny client `CopyButton` component.
  No `dangerouslySetInnerHTML` for post body; JSON-LD sanitized `.replace(/</g, '\u003c')`.
- **Headings + anchors:** `rehype-slug` + `rehype-autolink-headings` on every H2/H3.
  Anchor `#` 14px, `text-slate-300 hover:text-[#4f46e5]`, `aria-label="Link to section"`,
  appears on hover/focus only (no layout shift — `ml-2` reserved inline).
- **Byline / AI-badge / related:** see Component API table (§9). Byline links name →
  `/authors/musfiqur-rahman-saimon` (exact). Badge links → `/editorial-process` (exact).
  Related: max 3 same-silo (title + excerpt links), section hidden when <1 match.
- **Ad slots (D-11):** `<AdSlot id width height>` renders
  `<div aria-hidden="true" data-ad-slot={id} style={{width, height, minWidth: width, minHeight: height}} className="mx-auto overflow-hidden" />`.
  No script tags, no network, no visible content. Two instances: header `728×90`
  (`hidden md:block`), in-article `336×280`. Grep gate: zero `googlesyndication|adsbygoogle|doubleclick`.
- **Progress bar (`<ReadingProgress/>`):** `"use client"`, ONLY client component on article
  routes. Fixed top `fixed top-0 left-0 h-1 bg-[#4f46e5] z-50`, width = scroll fraction,
  passive scroll listener + `requestAnimationFrame`, cleanup on unmount. No other `use client`
  under `app/blog/` or article `components/`.
- **Interactivity ban (D-08):** no FAQ accordions, no share widgets, no comments,
  no newsletter forms, no popups. Grep gate: zero `Disqus|utterances|giscus|sharethis|addthis`.

## 7. Accessibility + CWV Budgets (SITE-01)

- **Budgets:** Lighthouse 90+ mobile on `/` + post template; LCP < 2.5s, INP < 200ms, CLS < 0.1.
  Enforcement: `lighthouserc.cjs` + `.github/workflows/lhci.yml` (`lhci autorun` on `/` +
  `/blog/best-ai-writing-assistants-2026`, assert performance ≥ 0.9, runs on PR + push to main).
  Tactics: zero webfonts, single client island, AVIF/WebP `next/image` with explicit dimensions,
  Shiki server highlighting, deferred Plausible, no other third-party scripts.
- **Contrast:** body `#171717` on `#ffffff` (15.9:1); muted `#475569` (slate-600) on white (7.5:1);
  accent `#4f46e5` on white 6.3:1 (links/buttons only, never body). Monogram white on `#4f46e5` (6.3:1).
- **Focus:** visible `:focus-visible` outline `2px solid #4f46e5 offset-2px` on all links/buttons/summary;
  anchor `#` appears on `:focus` as well as hover; skip-link `Skip to content` first in `<body>`.
- **ARIA/landmarks:** `header/main/footer/nav` landmarks; TOC `<nav aria-label="Table of contents">`;
  TL;DR `<aside aria-label="TL;DR summary">`; callouts `role="note"`; FAQ
  `<section aria-label="Frequently asked questions">`; ad slots `aria-hidden="true"`;
  progress bar `aria-hidden="true"` (decorative); code copy buttons labeled `Copy code`.
  Heading order strict: H1 → H2 → H3, no skipped levels (schema-gated in `check-seeds`).
- **Motion:** `prefers-reduced-motion` disables progress-bar transition + any smooth scroll.
- **Keyboard:** TOC links, details/summary, copy buttons, anchors all keyboard-operable; no traps.

  `sitemap.ts`/`robots.ts` read the same constants + frontmatter that render visible FAQ/breadcrumbs.
- **Archives deferred:** no `/blog` index, no tag pages, no pagination in Phase 1;
  when added (Phase 2) they ship `noindex` + CI crawl-consistency suite.
- **`sitemap.ts`/`robots.ts` minimal now:** list canonical 200-status posts + static trust pages;
  split-sitemap/diff-gated-lastmod logic extends (not retrofits) in Phase 2.
- **Related block contract stable:** `<RelatedPosts currentSlug silo>` same-silo max-3 fallback
  is the deterministic base the Phase-3 link-graph engine upgrades without changing the slot.
- **Noindex archives later:** homepage + posts indexable; future archive/tag/pagination =
  `robots: {index: false}` by default.

## 10. Do / Don't List

- ✅ DO: white bg / near-black text / single `#4f46e5` accent within the reserved list.
- ✅ DO: system font stack, zero webfonts, `next/image` AVIF/WebP with explicit dimensions.
- ✅ DO: TL;DR in first 100 words on every post; static FAQ list (3–5 genuine Q&As, never H2 paraphrases).
- ✅ DO: sticky desktop TOC + inline mobile `<details>`; heading anchors on every H2/H3.
- ✅ DO: byline + AI-badge on every post; real publisher facts verbatim; `rel="me noopener"` outbound.
- ✅ DO: invisible fixed-dimension ad reservations (`data-ad-slot`, `aria-hidden`, no scripts).
- ✅ DO: single client island (progress bar); Shiki server highlighting; deferred Plausible only.
- ✅ DO: flat `/blog/{slug}` URLs; canonicals from `SITE_URL` + validated slug; single-source strings.
- ❌ DON'T: dark mode, theme toggle, any `dark:` variant.
- ❌ DON'T: share widgets, comment systems, newsletter forms, popups, contact forms (`<form>` banned sitewide in Phase 1).
- ❌ DON'T: FAQ accordions — FAQs render as a static list in Phase 1.
- ❌ DON'T: fabricated identity — no second author, no AI headshots, no invented credentials/links.
- ❌ DON'T: webfonts (`next/font`, font CDN links, `@font-face`), remote font fetch in OG routes.
- ❌ DON'T: ad scripts (`googlesyndication|adsbygoogle|doubleclick` = build-gate fail).
- ❌ DON'T: comment/share vendor strings (`Disqus|utterances|giscus|sharethis|addthis` = build-gate fail).
- ❌ DON'T: `dangerouslySetInnerHTML` for post body; unsanitized JSON-LD (`.replace(/</g, '\u003c')` required).
- ❌ DON'T: category-in-URL slugs, sitemap ping endpoint, Google Indexing API for posts, GA4.
- ❌ DON'T: banned seed vocabulary — `delve`, `fast-paced world`, `game-changer`, `unlock the power`, `In today's digital age`.
