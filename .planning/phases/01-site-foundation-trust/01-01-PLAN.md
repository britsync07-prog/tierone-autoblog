<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN/edge → origin | Cloudflare cache rules decide what crawlers/users see; misconfiguration serves stale HTML or blocks Googlebot |
| Build → publish | Content Collections schema is the only gate; malformed frontmatter must fail the build, never publish silently |
| Third-party script → page | Plausible snippet is the sole script; any additional script widens supply-chain and CWV attack surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | S/E | Cloudflare cache + Vercel headers (`docs/edge-cdn.md`, `next.config.mjs`) | mitigate | Bypass-cache HTML rules + HSTS/nosniff/referrer/frame headers in config; Googlebot-UA curl verification in Plan 04 |
| T-01-02 | T | Plausible snippet (`app/layout.tsx`) | accept | Single deferred first-party-configured script, no cookies/PII; rationale: required analytics, minimal CWV cost, no banner needed |
| T-01-03 | I | `lib/site.ts` constants | mitigate | Single-source rule enforced: grep gate in acceptance criteria forbids hardcoded domain/brand duplicates |
</threat_model>
