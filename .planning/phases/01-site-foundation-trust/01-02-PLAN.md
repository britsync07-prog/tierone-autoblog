<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MDX content → rendered HTML | Seed/pipeline MDX is author-controlled; raw HTML in MDX and JSON-LD injection are XSS vectors |
| Frontmatter strings → OG image + metadata | Titles flow into edge-rendered images and `<head>`; markup/overlong input must be neutralized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | X (XSS) | MDX render + JSON-LD (`mdx-components.tsx`, post page) | mitigate | Shiki server-render only; JSON-LD `.replace(/</g, '\u003c')` sanitize; no `dangerouslySetInnerHTML` for post body; grep gate on sanitizer presence |
| T-02-02 | I/T | OG image title (`opengraph-image.tsx` ×2) | mitigate | Truncate to 110 chars + strip `[<>&"]` before draw; fixed 1200×630 canvas prevents layout abuse |
| T-02-03 | I | Metadata canonicals | mitigate | Canonicals built only from `SITE_URL` + validated slug (schema regex); no query-param reflection |
</threat_model>
