<plan_context>
## Phase Boundary Context
Phase 7 establishes the automated daily news ingestion and publishing engine for TierOne AutoBlog.
Plan 07-01 delivers the ingestion and deduplication foundation (NEWS-01):
1. **Multi-Source Free Ingestion**: Aggregates top stories from Hacker News (Firebase REST), Google News Tech (RSS), TechCrunch AI (RSS), The Verge Tech (Atom), and Ars Technica (RSS).
2. **Robust XML/Atom & Entity Parsing**: Zero-compilation parser with CDATA unwrapping, entity unescaping, and HTML stripping.
3. **24-Hour Freshness Gate**: Enforces a strict 24-hour publication window, rejecting stale or historical articles.
4. **Multi-Tier Deduplication**: Prevents duplicate reporting via URL normalization and 3-word shingle Jaccard similarity ($\ge 0.40$) against `content/news/covered.json`.
5. **Story Scoring & Priority Selection**: Ranks candidate stories using HN points, cross-feed mentions, high-intent entities (OpenAI, Anthropic, Claude, Gemini, Copilot, DeepSeek, Nvidia), and publication recency.
6. **Deterministic Offline Testability**: Complete test suite backed by static XML and JSON fixtures.

## Decisions Handled
- **D-01 (Zero-Paid APIs Policy):** Feeds use 100% free public REST and XML endpoints. No third-party paid news aggregators or API subscriptions.
- **D-02 (24-Hour Freshness Invariant):** Any story older than 24 hours relative to current execution time is filtered out to maintain breaking news relevance.
- **D-03 (Multi-Tier Deduplication):** Shingling + URL normalization against `content/news/covered.json` guarantees no duplicate posts or search cannibalization across feed cycles.
</plan_context>

     * Generates contiguous 3-token strings (e.g. `['anthropic', 'releases', 'claude', 'sonnet']` -> `{'anthropic releases claude', 'releases claude sonnet'}`).
     * If title has fewer than 3 tokens, returns single set containing joined tokens.
   - Implement `calculateJaccardSimilarity(setA: Set<string>, setB: Set<string>): number`:
     * Computes intersection size divided by union size.
   - Implement `loadCoveredLedger(ledgerPath?: string): CoveredLedger`:
     * Reads `content/news/covered.json`. Returns empty `{ version: 1, updatedAt: '', events: [] }` if missing or unparseable.

     * If Jaccard similarity $\ge$ `jaccardThreshold` (default 0.40), flags duplicate with reason identifying the existing story title.
     * Checks key entity token overlap: if candidate and an existing event share $\ge 3$ significant entity tokens (e.g. `['anthropic', 'claude', 'sonnet']`), flags duplicate.

<threat_model>
### Threat Ref T-07-01: Upstream Feed Malformation, XML Injection & Schema Drift
- **Threat:** External RSS or Atom feeds change XML element structures, include unescaped entity characters, CDATA bombs, or malicious markup injection that could cause the parsing process to crash, leak raw HTML, or corrupt the content pipeline.
- **Mitigation:** `cleanCdataAndEntities` recursively strips all CDATA delimiters, unescapes standard entities, and strips residual HTML tags (`<[^>]+>`). The parser validates publication dates using standard ISO parsing and rejects items without explicit title and link fields. All network fetches run under strict timeouts (`timeoutMs: 8000`) and handle errors per-feed without cascading failures.
- **Verification:** `tests/news-ingestion.test.ts` feeds malformed XML, missing tags, nested CDATA, and unescaped entities through `parseRssOrAtomXml` and asserts clean string normalization without process crashes.

### Threat Ref T-07-02: Duplicate Story Coverage & Keyword Cannibalization
- **Threat:** Multiple syndicated feeds report on the same major tech release across different days or URLs, leading to redundant blog posts that cannibalize Google rankings and violate originality standards.
- **Mitigation:** Multi-tiered deduplication: (1) URL normalization removes query parameters and protocols; (2) canonical domain and path matching; (3) 3-word shingle Jaccard similarity comparison ($J \ge 0.40$) against all stories covered in `content/news/covered.json` within a rolling 14-day window; and (4) entity token overlap checks.
- **Verification:** `tests/news-dedup.test.ts` creates mock covered events and tests that alternative headlines for the same story from competing news outlets are deterministically rejected with duplicate detection flags.
</threat_model>
