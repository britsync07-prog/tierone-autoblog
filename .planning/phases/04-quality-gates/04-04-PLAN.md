## Phase Boundary Context
Hallucinations and false statistics destroy publisher EEAT and invite Google algorithmic penalties. Plan 04-04 implements the two-tier fact-checking engine: auto-excising soft marketing fluff while strictly quarantining fabricated numbers, planted false statistics, and ungrounded claims.

## Decisions Handled
- D-04: Two-Tier Claim Handling (Fluff auto-excised; fabricated/planted false stats trigger immediate quarantine)
- D-05: Extraction + Cached Ground Truth & Keyless Search (Structured LLM extraction `qa-extract-claims`, SERP/brief cross-check, keyless search, mandatory named source + year/as-of date)
</plan_context>

<task id="04-04-01" wave="3">
<description>
Implement two-tier fact-checking and claim verification engine in `lib/pipeline/qa/fact-check.ts`.
</description>
<actions>
1. Create `lib/pipeline/qa/fact-check.ts`:
   - Zod schema for claim extraction:
     ```ts
     export const extractedClaimsSchema = z.object({
       stats: z.array(z.object({
         statement: z.string(),
         numericalValue: z.string(),
         sourceCited: z.string().nullable(),
         yearOrAsOf: z.string().nullable(),
         isDirectlyVerifiable: z.boolean(),
       })),
       fluffStatements: z.array(z.string()),
       factualClaims: z.array(z.object({
         claim: z.string(),
         entity: z.string(),
         verifiable: z.boolean(),
       })),
     });
     ```
   - LLM Task `qa-extract-claims`:
     - System prompt instructing model to identify all quantitative/statistical claims, ungrounded marketing hype, and core factual statements.
     - Supports `QA_FIXTURE=1` reading canned fixtures for zero-cost testing.
   - Verification Logic (`verifyClaims`):
     - Ground truth sources:
       - Cached SERP top-3 snippets (`serpTop3`)
       - Brief facts in `content/briefs/{id}.md`
       - Keyless public search (e.g. DuckDuckGo / Wikipedia keyless query) if stat is specific and unverified in brief.
     - Tier 1: Soft fluff statements (e.g. "This revolutionary tool is universally acknowledged as 10x superior") $\rightarrow$ flagged for auto-excision.
     - Tier 2:
       - Statistical claim missing named source + year/as-of date $\rightarrow$ FAIL (quarantine).
       - Statistical claim contradicted by ground truth or timeline (e.g., claiming 78% of code written by AI in 1994) $\rightarrow$ CRITICAL FAIL (immediate quarantine).
   - Sanitizer (`sanitizeDraftClaims`):
     - Takes raw MDX and list of Tier 1 fluff statements.
     - Removes or cleans the fluff statements from the draft prose while preserving markdown formatting and structure.
</actions>
