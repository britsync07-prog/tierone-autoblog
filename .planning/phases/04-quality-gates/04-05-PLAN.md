<task id="04-05-02" wave="4">
<description>
Implement pipeline QA stage runner in `lib/pipeline/stages/qa.ts` and register in `lib/pipeline/run.ts`.
</description>
<actions>
1. Create `lib/pipeline/stages/qa.ts`:
   - Implements `export async function runStage(ctx: StageContext): Promise<StageResult>`.
   - Discovers entries at `drafted` stage that lack `qa.passedAt`.
   - For each candidate entry:
     - Load draft from `content/posts/${entry.draft.slug}.mdx`.
     - Step 1: Pre-filter blocklist (`checkBlocklist`, `checkAuthorByline`). If fail $\rightarrow$ quarantine (`failedGate: 'blocklist'`).
     - Step 2: Link crawler (`crawlLinks`). If broken internal link $\rightarrow$ quarantine (`failedGate: 'link-crawler'`). If broken external $\rightarrow$ sanitize anchors.
     - Step 3: Originality shingler (`checkOriginality`). If Jaccard > 0.70 $\rightarrow$ quarantine (`failedGate: 'originality'`).
     - Step 4: Fact check (`verifyClaims`). If planted false stat or critical contradiction $\rightarrow$ quarantine (`failedGate: 'fact-check'`). If fluff $\rightarrow$ sanitize body.
     - Step 5: Information gain (`evaluateInformationGain`). If score < 3 $\rightarrow$ quarantine (`failedGate: 'information-gain'`).
     - On any Gate Failure:
       - Calls `quarantineDraft` (moves file to `content/quarantine/${id}.mdx`, writes `{id}-report.json`).
       - Updates entry in shard: `entry.stage = 'quarantined'`, sets `entry.quarantine = { failedRule, score, reportPath, quarantinedAt }`.
       - Calls `recordQaFailure({ id: entry.id, failedRule })`.
       - Logs quarantine notice.
     - On Full Gate Pass:
       - If body was sanitized (fluff removed or dead external links stripped), rewrites `content/posts/${entry.draft.slug}.mdx`.
       - Updates entry in shard: sets `entry.qa = { passedAt: new Date().toISOString(), informationGainScore, claimsChecked }`.
       - Calls `recordQaSuccess()`.
       - Saves shard.
2. In `lib/pipeline/run.ts`:
   - Add `'qa'` to `STAGE_ORDER`:
     ```ts
     export const STAGE_ORDER = ['expand', 'brief', 'outline', 'assets', 'draft', 'qa'] as const;
     ```
3. In `package.json`:
   - Add `"pipeline:qa": "tsx lib/pipeline/run.ts --stage qa"`
</actions>
<verification>
Run `npm run pipeline:qa` on existing drafted post `best-ai-writing-tools.mdx` and verify it evaluates and records QA pass without errors.
</verification>
</task>
