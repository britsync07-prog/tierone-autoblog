## Phase Boundary Context
Gate 1 and Gate 2 are fast, deterministic pre-checks. If a draft touches forbidden YMYL domains, fakes author identity, or introduces broken internal links, it must be quarantined immediately without wasting LLM tokens or risking crawler 404 penalties.

## Decisions Handled
- D-06: Deterministic Fast-Fail Pre-Filter (Regex YMYL scanner + Author `musfiqur-rahman-saimon` + `/about` & `/editorial-process` links)
- D-09: Deterministic Link Crawl Gate (Internal routes against Next.js route table; external links probed with 4s HTTP HEAD)
</plan_context>

<task id="04-02-01" wave="2">
<description>
Implement deterministic YMYL topic blocklist and publisher byline validator in `lib/pipeline/qa/blocklist.ts`.
</description>
<actions>
1. Create `lib/pipeline/qa/blocklist.ts`:
   - Define pre-compiled regexes for YMYL topics:
     - Tax: `\b(tax (return|deduction|credit|bracket|loophole)|irs filing|write off expenses|file taxes)\b`
     - Banking: `\b(bank account|checking account|wire transfer|routing number|swift code|open a bank)\b`
     - Credit: `\b(credit score|repair credit|fix credit|fico score|credit bureau|boost your credit score)\b`
     - Health/Medical: `\b(medical diagnosis|prescription dosage|cure disease|treat symptom|fda approved|dosage guide)\b`
     - Finance/Investment: `\b(stock pick|buy stock|investment advice|guaranteed return|cryptocurrency signal|crypto pumps)\b`
   - `export interface BlocklistResult`:
     ```ts
     export interface BlocklistResult {
       pass: boolean;
       violatingTerms: string[];
       category?: string;
     }
     ```
   - `export function checkBlocklist(text: string): BlocklistResult`
     - Scans text (case-insensitive) against all categories.
     - Returns `{ pass: false, violatingTerms, category }` if any match found; else `{ pass: true, violatingTerms: [] }`.
   - `export interface BylineResult`:
     ```ts
     export interface BylineResult {
       pass: boolean;
       reasons: string[];
     }
     ```
   - `export function checkAuthorByline(rawMdx: string): BylineResult`
     - Parses frontmatter and body.
     - Verifies `author` is `musfiqur-rahman-saimon` (or if frontmatter lacks author, checks if body attributes author).
     - Verifies body includes explicit links to `/about` AND `/editorial-process`.
     - Returns `{ pass: true, reasons: [] }` if compliant; else `{ pass: false, reasons }`.
</actions>

<task id="04-02-02" wave="2">
<description>
Implement deterministic pre-publish link crawler in `lib/pipeline/qa/link-crawler.ts`.
</description>
<actions>
1. Create `lib/pipeline/qa/link-crawler.ts`:
   - Link extraction regex to find all `[text](url)` markdown links and `<a href="url">` tags.
   - Internal route validation:
     - Build route table from:
       - Static pages: `/`, `/about`, `/editorial-process`, `/terms`, `/privacy`, `/sitemap.xml`, `/robots.txt`
       - All published post slugs in `content/posts/*.mdx` (`/posts/${slug}`)
       - Category / silo hubs: `/ai-writing`, `/ai-coding`, `/ai-image`, `/ai-productivity`, `/ai-guides`
     - If internal link has anchor `#heading`, strip anchor and check route base.
     - Unmatched internal link returns `{ valid: false, url, error: 'Internal 404: route not found' }`.
   - External link validation:
     - For `http://` or `https://` URLs:
     - Probe URL using native Node.js `fetch(url, { method: 'HEAD', signal: AbortSignal.timeout(4000), headers: { 'User-Agent': 'TierOneAutoBlog-LinkChecker/1.0' } })`.
     - If status 405 (Method Not Allowed), retry with `GET` and abort once headers arrive.
     - If status 404, 410, 500+, or DNS failure:
       - Flag as broken external link.
   - `export interface LinkCrawlResult`:
     ```ts
     export interface LinkCrawlResult {
       pass: boolean;
       brokenInternal: string[];
       brokenExternal: string[];
       sanitizedBody?: string; // body with broken non-critical external anchors stripped
     }
     ```
   - `export async function crawlLinks(body: string, options?: { postsDir?: string; probeExternal?: boolean }): Promise<LinkCrawlResult>`
     - If `brokenInternal.length > 0`: `pass = false` (broken internal link is a hard failure $\rightarrow$ quarantine).
     - If broken external link found: auto-strips `[anchor](brokenUrl)` to plain `anchor` and logs warning, setting `sanitizedBody`.
</actions>

</task>
