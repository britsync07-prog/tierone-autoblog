## Phase Boundary Context
To survive Google's scaled-abuse and spam-update policies, automated articles must never be near-duplicates of existing content or scrape-and-spin variations of top-3 SERP articles. Plan 04-03 delivers a deterministic N-gram Jaccard shingling engine that enforces a strict 0.70 similarity ceiling.

<task id="04-03-01" wave="2">
<description>
Implement deterministic N-gram Jaccard shingling engine in `lib/pipeline/qa/shingle.ts`.
</description>
<actions>
1. Create `lib/pipeline/qa/shingle.ts`:
   - Text Tokenization:
     - Strip markdown fences, frontmatter, HTML tags, headers, and code blocks.
     - Lowercase and normalize whitespace.
     - Split into clean word tokens (filtering out short punctuation tokens).
   - $N$-gram Shingling (`createShingles(tokens: string[], n = 5): Set<string>`):
     - Produces sliding window of $n$ consecutive tokens joined by spaces.
     - Returns `Set<string>` of shingles.
   - Jaccard Math (`jaccardSimilarity(setA: Set<string>, setB: Set<string>): number`):
     - If both sets empty, returns 0.
     - Calculates $|A \cap B| / |A \cup B|$.
     - Returns rounded float in range [0.0, 1.0].
   - Corpus Originality Check (`checkOriginality(draftText: string, options?: { postsDir?: string; serpSnippets?: string[]; threshold?: number }): OriginalityResult`):
     - `threshold`: default 0.70.
     - Compares candidate draft shingles against:
       1. Every `.mdx` file in `content/posts/` (excluding the candidate draft itself if already landed).
       2. Any provided cached SERP snippets or brief competitor bodies.
     - If any comparison exceeds `threshold`:
       - Returns `{ pass: false, maxSimilarity, matchedSource, threshold }`.
     - Else returns `{ pass: true, maxSimilarity, threshold }`.
</actions>
<verification>
Create `tests/qa-shingle.test.ts` verifying:
1. Exact match returns 1.0.
2. Completely disjoint text returns 0.0.
3. Slightly edited text with word swaps returns realistic ratio (e.g. 0.75-0.85) and triggers `pass === false` (> 0.70).
4. Substantially original post (distinct topic/flow) returns low ratio (e.g. 0.15) and triggers `pass === true`.
</verification>
