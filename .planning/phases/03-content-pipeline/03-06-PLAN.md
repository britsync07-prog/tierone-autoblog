```typescript
import { draftSchema, comparisonSchema } from '../draft-schema';
import { completeJson } from '../llm';

/** Model payload — zod-validated structured JSON from the draft-body call. */
const draftPayloadSchema = z.object({
  title: z.string(),        // 50–60 chars enforced later through draftSchema.parse
  description: z.string(),  // 150–160 chars enforced through draftSchema.parse
  tldr: z.string(),         // ≤100 words enforced through draftSchema.parse
  faqs: z.array(z.object({ q: z.string(), a: z.string() })).min(3).max(5),
  comparison: comparisonSchema.optional(),  // only permitted when outline flagged the slot
  body: z.string(),         // markdown; word band + H2 fidelity enforced by STAGE assertions
});

export async function runStage(ctx: StageContext): Promise<StageResult>;
```
Stage context additions (mirror 03-05's assets-stage conventions if their names differ — check its SUMMARY first):
- `ctx.briefsDir?: string` — default `content/briefs`; override points at fixture briefs in tests.
- `ctx.postsDir?: string` — default `content/posts`; override in tests so the gate runs on fixture output.
- Outline file location: `{briefsDir}/{silo}/{id}-outline.md` (per 03-03/03-05).

Stage behavior (PIPE-03, D-12 defense in depth, D-04 visible trail):
1. Queue = listPromotable(registryDir, 'outlined', 'drafted', DRAFTS_PER_RUN) where `DRAFTS_PER_RUN = 2` (named constant; mirrors 03-03's real-run brief cap so one chain pass paces across silos — document the rationale in code).
2. Attempt ceiling: `MAX_DRAFT_ATTEMPTS_PER_ENTRY = 5` (named constant). Entries with `draft?.attempts >= 5` are SKIPPED this run with a note (`template-failure ceiling`) — no LLM spend, stays 'outlined', visible in summary. Nothing is auto-rejected: the D-04 trail is attempts + lastError, human review happens through the registry (git).
3. Preconditions — ALL must hold or the entry is skipped (NOT rejected; stage stays 'outlined'; note explains which):
   - `entry.outline?.lint === 'pass'` AND `entry.outline?.completedAt` (re-assert)
   - `entry.images?.completedAt` present + hero src/alt well-formed (03-05 precondition)
   - `Array.isArray(entry.paa) && entry.paa.length >= 3` (FAQ source quality floor)
   - outline file exists at `{briefsDir}/{silo}/{id}-outline.md`
4. Outline parse (zero-dep text, mirroring check-outline.mjs rule 4 exactly so the two agree):
   - H2s = the real content `^## ` headings inside the `## Structure` section; literal `[comparison-table slot]` marker = outcome flag (`outlineText.includes('[comparison-table slot]')`); zero parsed H2s → precondition failure note.
5. Model call: `completeJson({ task: 'draft-body', zodSchema: draftPayloadSchema, messages: [...] })`.
   - System prompt (template contract, PITFALLS guardrails inlined): the H1 (50–60 chars) IS `title`; meta description 150–160; TL;DR ≤100 words; body 1,500–2,500 words with EXACTLY the supplied H2/H3 structure (each supplied H2 becomes a `## {h2}` in the same order); FAQs answered ONLY for the supplied PAA questions (q strings VERBATIM from `entry.paa[]` — inventing questions is a hard template violation); comparison rows supplied ONLY when the outline flags the table slot: qualitative verdict cells justified by the top-3 SERP coverage + gaps, no invented metrics/quotes/URLs (PITFALLS: hallucinated data), final H2 = conclusion with a sentence linking to `/about`; write for a US reader (en-US), no banned filler phrases (delve, fast-paced world, game-changer, unlock the power, in today's digital age); in-article image cues (alt strings from entry.images.inArticle) may inform section prose but resolve to NO `{{image:` markers and no `[comparison-table slot]` markers in the final body.
   - User prompt: outline file text + entry keyword/silo + `serpTop3` URLs-as-data + `paa[]` + in-article alt strings.
6. Stage assertions (defined BEFORE any write; any failure = attempt, no file touched):
   - body word count = `body.split(/\s+/).filter(Boolean).length` in [1500, 2500]
   - every outline H2 appears in the body (normalized case/whitespace `body.includes('## ' + h2)`)
   - every `payload.faqs[].q` normalized-matches (lowercase, collapse whitespace, strip trailing `?`) a member of `entry.paa[]` — an invented FAQ fails here even if the prompt failed
   - when outline flagged the slot: `payload.comparison` PRESENT and the assembled note contains 'pricing' (template constant `Prices shift often — confirm pricing on vendor pages before choosing.` per D-14/seed-01 pattern); when NOT flagged: `payload.comparison` must be ABSENT
7. Assemble + validate + write:
   - frontmatter from payload + entry data: slug=entry.id, silo=entry.silo, publishedAt=updatedAt=<now ISO>, heroImage={ src: entry.images.hero.src, alt: entry.images.hero.alt }, faq from payload.faqs, comparison.note = the pricing-constant insertion
   - `draftSchema.parse(frontmatter)` (03-04 contract) — parse error ⇒ attempt-trail, no write
   - atomically write `content/posts/{id}.mdx` (frontmatter fences + body; same file shape as seeds)
8. Gate BEFORE advance: `spawnSync(process.execPath, ['scripts/check-template.mjs', postsDir], { encoding: 'utf8' })` (cwd = repo root). Exit 1 → delete the just-written file, `draft = { slug: id, attempts: prev+1, lastError: first 200 chars of gate stderr/stdout }`, entry stays 'outlined', continue others.
9. Gate pass → `advance(entry, 'drafted')` and persist `draft = { slug: id, landedAt: <now ISO>, attempts: prev+1 }`. `spentUsd` stays 0 (D-02 envelope is DataForSEO-specific — 03-05/03-06 spend is reported via notes, e.g. `drafted 2 posts, image assets regenerated where flagged`).
10. Idempotency: entries with stage 'drafted' are never requeued (listPromotable guarantees it).

Fixture mode for offline verification: env `PIPELINE_DRAFT_FIXTURE=1` routes all completeJson calls through canned payloads exported from draft.ts (`DRAFT_FIXTURE_PAYLOADS`, variants GOOD / BAD_FAQ / BAD_BAND / BAD_H2). Zero network, zero LLM spend in this plan's tests; the REAL run (task 3) uses live keys.

scripts/check-template.mjs rules (zero-dep Node ESM, EXACT family idiom of check-seeds.mjs: split frontmatter on `---` fences, line-based parse, "N passed" output, exit 0/1, optional dir argument defaulting to content/posts; BANNED array copied from check-seeds.mjs with a `// keep in sync with scripts/check-seeds.mjs` comment; SILO_SLUGS grepped as TEXT from lib/silos.ts — the site module is never imported, same parity trick as check-crawl.mjs):
1. Frontmatter fences present (malformed → FAIL).
2. title present, 50–60 chars.
3. description 150–160 chars.
4. slug matches `/^[a-z0-9]+(?:-[a-z0-9]+)*$/`.
5. publishedAt + updatedAt present and Date-parseable (loose ISO check).
6. faq: 3–5 `q:`/`a:` pairs counted line-based (breaks → FAIL).
7. tldr present and ≤100 words (`split(/\s+/).filter(Boolean)` — no floor here; the quality floor is the stage's JOB, the gate is corpus-agnostic so seeds pass identically).
8. silo value ∈ SILO_SLUGS (text-grepped tuple).
9. Body ≥3 `^## ` headings.
10. Body contains an `/about` link (CTA template constant).
11. No banned phrase (same BANNED list as check-seeds: delve, fast-paced world, game-changer, unlock the power, in today's digital age).
12. Body contains NO `^# ` H1 line (title lives in frontmatter).
13. Body contains NO unresolved markers: `[comparison-table slot]`, `{{image:`.
14. comparison frontmatter accepted via presence-check (`comparison:` + `columns:` + ≥2 `- cells:` lines) — shape is the build's zod job, identical convention to check-seeds' conditional added in 03-04.

This rule set is deliberately seed-compatible: every existing seed + the 03-04 retrofit satisfy it by construction (they all pass the phase-1 strict template). The 1,500–2,500 word band is intentionally NOT in the gate — the draft stage enforces it (PIPE-03's scope is drafts; altering seeds' length is out of scope).
