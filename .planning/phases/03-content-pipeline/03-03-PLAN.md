llm.ts contract (new):
```typescript
export type LlmTask = 'summarize' | 'title-desc' | 'outline-body' | 'generic-structured';
export interface LlmMessage { role: 'system' | 'user'; content: string; }
export interface LlmJson<T> { parsed: T; raw: string; provider: 'anthropic' | 'openai-fallback' | 'fixture'; }
export class LlmNoCredentialsError extends Error {}
export class LlmBadStructuredOutputError extends Error {}

// FIXTURE MODE: internal canned responses keyed by task+hash (below), used for
// deterministic verification without API spend. Routed on env if the provider
// wrapper requires to boot the fixtures, else try fixtures via env.
export async function completeJson<T>(opts: {
  task: LlmTask; zodSchema: import('zod').ZodType<T>; messages: LlmMessage[]; fixtureKey?: string; jsonFixture?: unknown;
}): Promise<LlmJson<T>>;
```
- Provider routing (STACK locked split): outline-body → Anthropic primary (long-structure quality; env ANTHROPIC_DRAFT_MODEL default `claude-sonnet-4-5`), narrow (summarize/title-desc) → OpenAI cheap (env OPENAI_NARROW_MODEL default `gpt-5-mini`). OpenAI is ALSO the fallback when Anthropic errors (outage shape: try fallback provider once, then throw).
- Structured output: request JSON; validate with the passed zod schema; LlmBadStructuredOutputError on mismatch after 1 repair retry (append validation error, ask model to fix).
- Keys from env (ANTHROPIC_API_KEY, OPENAI_API_KEY). Missing key for the ROUTED provider → LlmNoCredentialsError naming the var.
- Fixture mode: when opts.jsonFixture is provided, skip network entirely and run the SAME zod validation path on the fixture — that is how this plan verifies stage logic deterministically.
- SDKs: `import Anthropic from '@anthropic-ai/sdk'` and `import OpenAI from 'openai'` (installed in 03-01). Clients constructed lazily per call (no module-level singletons that pin dead connections in long runs). Max output tokens explicit per task (summarize 2000, title-desc 400, outline-body 4000). 60s AbortController timeout, 1 retry on 5xx/429 (backoff 5s), never retry 4xx.

Brief artifact template — content/briefs/{silo}/{id}-brief.md (D-11 committed Markdown; plain doc, NOT a content collection):
```markdown
# Gap brief: {keyword}

- Silo: {silo} | Status source: registry entry {id} | As of: {metricsAsOf}
- Metrics (US): volume {v}, KD {kd}
- Target reader geo: US (publish en-US single-locale)

## What the top-3 cover
1. {serpTop3[0].url} — {one-line what the page covers, LLM-compressed from title}
2. {serpTop3[1].url} — ...
3. {serpTop3[2].url} — ...

## Gaps we can win
- {2-4 bullets derived from the top-3 compression + our differentiators: current-version facts, verdict tables, hands-on testing notes, explicit trade-offs}

## People also ask (captured {serpAsOf})
- {PAA questions, verbatim from registry paa[]}

## Image brief (PIPE-05 forward-planning)
- Hero: {16:9 concept one-liner}
- In-article: {0-2 concepts tied to specific H2s, or "none"]

## Judgement
{2-3 sentences: should-this-exist — is the keyword worth a 2000-word post vs the top-3? If NOT, say so plainly and recommend rejection on the next promotion pass.}
```

Outline artifact template — content/briefs/{silo}/{id}-outline.md:
```markdown
# Outline: {keyword}

- Silo: {silo} | Brief: {id}-brief.md | Lint target: check:outline

## Meta
- H1 (50-60 chars): {H1}
- Meta description (150-160 chars): {meta}
- TL;DR (<=100 words): {tldr}
- Slug: {id}

## Structure
## {H2 1 — target ~{n} words}
### {H3 ...}
## {H2 2 ...}
...
[comparison-table slot] {only when the brief/table earns it — see D-14}

## FAQs (PAA-derived, 3-5)
- Q: {question from paa[]}
  A-angle: {one-line answer angle}

## Conclusion + CTA
- CTA: link to /about (template constant)

## Image slots
- hero: {16:9 concept} (ALWAYS)
- in-article-1: {concept or none}
- in-article-2: {concept or none}
```

check-outline.mjs lint rules (zero-dep, family idiom of check-seeds; parse the markdown files as text):
1. H1 line length 50-60 chars. 2. Meta description 150-160. 3. TL;DR present, <=100 words, >=10 words. 4. >=3 `^## ` headings (excluding its own `## Meta`/`## Structure` boilerplate? — count REAL content H2s listed under ## Structure). 5. FAQ block has 3-5 `- Q:` entries. 6. Every FAQ Q must appear in the brief's PAA capture (cross-file check: brief file in same dir; fail if invented). 7. Image slots block present with `hero:` line (in-article lines optional). 8. `[comparison-table slot]` marker allowed at most once. 9. No `_tbd_`/`TBD` placeholders anywhere. Output `N passed`, exit 0/1. Script accepts an optional directory argument (defaults `content/briefs`) so fixtures can run the gate on test data.
