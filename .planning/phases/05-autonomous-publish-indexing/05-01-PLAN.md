<plan_context>
## Phase Boundary Context
Phase 5 automates publishing and search engine discovery without human gates.
Plan 05-01 establishes the dual-track indexing infrastructure (AUTO-03):
1. **IndexNow Track** (Bing, Yandex, Seznam, Naver, Yep): Key verification route + static fallback + batch submission dispatcher.
2. **Google Track**: Sitemaps API submission via official `googleapis` with graceful degradation (`'skipped-no-creds'`) when service account credentials are not yet configured.
3. **Unified Logging**: Dispatches both tracks per published post and persists structured logs to `content/keywords/indexing-log.json`.

## Decisions Handled
- **D-07:** IndexNow Track via Next.js rewrite route (`next.config.mjs` -> `app/api/indexnow/route.ts`) + prebuild static sync `public/{key}.txt` + POST to `https://api.indexnow.org/indexnow`.
- **D-08:** Google Track via Search Console Sitemaps API (`googleapis` service account client).
- **D-09:** Graceful Credential Degradation (unconfigured Google credentials log `'skipped-no-creds'` and never crash the workflow).
</plan_context>

<task id="05-01-01" wave="1">
<description>
Implement IndexNow key verification route handler, URL rewrite, static sync script, and IndexNow HTTP POST dispatcher with complete error handling.
</description>
<action>
1. Update `next.config.mjs` to include rewrite rule:
   ```javascript
   async rewrites() {
     return [
       {
         source: '/:key([a-zA-Z0-9_-]+).txt',
         destination: '/api/indexnow?key=:key',
       },
     ];
   }
   ```
2. Create `app/api/indexnow/route.ts`:
   - Enforce `export const dynamic = 'force-dynamic'`.
   - Read `key` from request search params: `request.nextUrl.searchParams.get('key')`.
   - Compare with `process.env.INDEXNOW_KEY`.
   - If missing, mismatching, or empty: return `new NextResponse('Not Found', { status: 404 })`.
   - If matching: return `new NextResponse(configuredKey, { status: 200, headers: { 'Content-Type': 'text/plain; charset=utf-8', 'Cache-Control': 'public, max-age=86400, s-maxage=86400' } })`.
3. Create `scripts/sync-indexnow-key.mjs`:
   - Checks `process.env.INDEXNOW_KEY`.
   - If valid format (`/^[a-zA-Z0-9_-]{8,128}$/`), writes `${key}` to `public/${key}.txt`.
4. Create `lib/pipeline/indexing/indexnow.ts`:
   - Export interfaces: `IndexNowPayload`, `IndexNowResult`, `IndexNowOptions`.
   - Function `submitIndexNow(options: IndexNowOptions): Promise<IndexNowResult>`:
     - Derives `host` from `options.siteUrl` (hostname only).
     - Validates `key` (8 to 128 alphanumeric/dash characters).
     - Derives `keyLocation`: `${siteUrl}/${key}.txt`.
     - Validates `urlList` (up to 10,000 URLs).
     - POSTs to `https://api.indexnow.org/indexnow` with headers `Content-Type: application/json; charset=utf-8`.
     - Maps HTTP responses:
       - 200 / 202: `{ success: true, status: 'submitted', httpStatus: res.status }`.
       - 400 / 403 / 422 / 429 / 5xx: `{ success: false, status: 'error', httpStatus: res.status, message: res.statusText }`.
     - Catches network errors and returns `{ success: false, status: 'error', message: err.message }`.
5. Create `tests/indexing-indexnow.test.ts`:
   - Tests `app/api/indexnow/route.ts` behavior with matched key (200 text/plain), mismatched key (404), missing env var (404).
   - Tests `submitIndexNow` payload serialization: correct `host`, `key`, `keyLocation`, `urlList`.
   - Tests `submitIndexNow` status handling with mock server / mocked fetch (200 OK, 202 Accepted, 403 Forbidden, network error).
</action>

<task id="05-01-02" wave="1">
<description>
Install `googleapis`, implement Google Search Console Sitemaps API client with graceful degradation (D-08, D-09), and create unified dual-track coordinator writing to `content/keywords/indexing-log.json`.
</description>
<action>
1. Install `googleapis` dependency: `npm install googleapis`.
2. Create `lib/pipeline/indexing/google-search-console.ts`:
   - Export interfaces: `GscSubmitOptions`, `GscSubmitResult`.
   - Function `submitGscSitemap(options: GscSubmitOptions): Promise<GscSubmitResult>`:
     - Checks `options.clientEmail ?? process.env.GOOGLE_SERVICE_ACCOUNT_EMAIL`.
     - Checks `options.privateKey ?? process.env.GOOGLE_PRIVATE_KEY`.
     - If neither email nor private key is present:
       - Returns `{ status: 'skipped-no-creds', siteUrl: options.siteUrl, sitemapUrl: options.sitemapUrl, message: 'Google Search Console credentials not provisioned (skipped-no-creds).' }`.
     - Sanitizes private key: `privateKey.replace(/\\n/g, '\n')`.
     - Instantiates `new google.auth.GoogleAuth({ credentials: { client_email, private_key }, scopes: ['https://www.googleapis.com/auth/webmasters'] })`.
     - Calls `google.searchconsole({ version: 'v1', auth }).sitemaps.submit({ siteUrl, feedpath: options.sitemapUrl })`.
     - Returns `{ status: 'submitted', siteUrl: options.siteUrl, sitemapUrl: options.sitemapUrl }`.
     - On exception: returns `{ status: 'error', siteUrl: options.siteUrl, sitemapUrl: options.sitemapUrl, message: err.message }` without throwing.
3. Create `lib/pipeline/indexing/index.ts`:
   - Export interface `IndexingLogEntry` and `IndexingRunResult`.
   - Function `dispatchDualTrackIndexing(options: { postUrl: string; slug: string; sitemapUrl: string; siteUrl: string; keywordsDir?: string }): Promise<IndexingRunResult>`:
     - Dispatches `submitIndexNow` with post URL and sitemap URL.
     - Dispatches `submitGscSitemap` with sitemap URL.
     - Appends log entry to `content/keywords/indexing-log.json` containing `{ timestamp, slug, postUrl, sitemapUrl, indexnow, gsc }`.
     - Returns aggregate status.

<threat_model>
### Threat Ref T-05-01: Key Verify Route Token Disclosure & Mismatch
- **Threat:** Unauthenticated crawlers probe arbitrary `/[key].txt` paths attempting to discover or spoof verification tokens, or malformed dynamic routes conflict with root silo routes (`app/[silo]/page.tsx`).
- **Mitigation:** Dynamic route is isolated via explicit rewrite in `next.config.mjs` matching regex `/:key([a-zA-Z0-9_-]+).txt` forwarding to `/api/indexnow?key=:key`. Handler performs strict equality comparison with `process.env.INDEXNOW_KEY` and returns 404 for any mismatch or missing configuration.
- **Verification:** Unit test `tests/indexing-indexnow.test.ts` tests random keys, empty keys, and mismatched keys, verifying HTTP 404 response.

### Threat Ref T-05-02: Search Console Credential Leakage & Pipeline Crashing
- **Threat:** Private key strings or service account credentials leak into console logs or crash the unmonitored publishing workflow when secrets are unconfigured.
- **Mitigation:** `submitGscSitemap` checks credentials early, never interpolates raw private keys into error strings or logs, catches all Google API exceptions internally, and records an honest `'skipped-no-creds'` status in `indexing-log.json`.
- **Verification:** Unit test `tests/indexing-gsc.test.ts` verifies that omission of `GOOGLE_PRIVATE_KEY` yields clean `{ status: 'skipped-no-creds' }` with no unhandled rejection and no secret output in stdout/stderr.
</threat_model>
