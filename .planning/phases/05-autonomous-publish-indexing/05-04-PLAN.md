Plan 05-04 implements the Pinned 20-Query Evaluation Benchmark (AUTO-04):

<threat_model>
### Threat Ref T-05-07: Silent Prompt Degradation & Ranking Collapse
- **Threat:** Modifications to LLM prompts, model version updates, or template changes subtly drop comparison tables, strip edge-case disclosures, or produce generic text that falls below Google's Information Gain ranking threshold, causing organic traffic collapse.
- **Mitigation:** The pinned 20-query benchmark is executed in CI before any merge. It enforces that all 20 queries pass structure, schema, byline, and topic safety checks, and the mean Information Gain score across the entire portfolio remains $\ge 3.0 / 4.0$. Any drop blocks the commit/PR.
- **Verification:** Regression test `tests/eval-20.test.ts` asserts that synthetic outputs meet $\ge 3.0 / 4.0$ Information Gain and verifies that artificially degraded outputs fail the regression assertion.
</threat_model>
